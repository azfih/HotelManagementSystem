# 🏨 Hotel Management System - Java Project

This is a basic Hotel Management System developed in **Java** as a semester project for the **Object Oriented Programming (OOP)** course during the 3rd semester.

## 📌 Features

- 🧳 Guest Reservations  
- 🛏️ Room Management  
- 👨‍💼 Staff Management  
- 📦 Inventory Management  
- 💵 Billing System  
- 🏢 Hotel Info Management  
- 👮 Manager & Staff Login  
- 🧾 Reports & Total Earnings Overview

## 💡 Technologies Used

- Java (Swing for GUI)
- Object Serialization (File-based storage)

## 🛠️ How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/hotel-management-system.git
2. Open the project in any Java IDE (e.g., **NetBeans**, **IntelliJ**).
3. Run the `HotelManagementSystem3.java` file.
4. Use the GUI to navigate as a **Guest**, **Staff**, or **Manager**.

## 📁 File Structure

- `HotelManagementSystem3.java` – Main project file containing all classes.
- `Room.txt`, `Staff.txt`, `Inventory.txt`, `Reservation.txt`, etc. – Serialized data files generated at runtime.
